Política de Privacidad - Padel Tracker

Última actualización: 08/01/2026

Introducción

Padel Tracker (la “Aplicación”) es ofrecida por Chanchoc (“Proveedor del Servicio”) como servicio gratuito, en estado “TAL CUAL”. Esta política explica cómo se recopila, usa y protege tu información.

Información que recopilamos

  • Dirección IP del dispositivo
  • Páginas visitadas en la Aplicación, fecha y hora, y tiempo de permanencia
  • Sistema operativo del dispositivo
  • Tiempo de uso de la Aplicación
  • Datos de cuenta (email) y datos de uso (ej.: partidos, jugadores que agregas)

No se recopila información de ubicación precisa del dispositivo.

Uso de la información

  • Operar y mejorar la Aplicación
  • Contactarte con avisos importantes o promociones
  • Generar estadísticas personalizadas

Acceso de terceros

Solo se comparte información agregada y anonimizada con servicios externos para mejorar la Aplicación. Podemos divulgar información:

  • Si la ley lo requiere
  • Para proteger derechos, seguridad o investigar fraude
  • Con proveedores de servicios que actúan en nuestro nombre y bajo esta política

Opt-out

Podés detener toda recopilación de datos desinstalando la Aplicación mediante los procesos estándar de tu dispositivo o tienda.

Retención

Retenemos los datos mientras uses la Aplicación y por un tiempo razonable después. Para solicitar eliminación, escribinos a chanchoc.dev@gmail.com.

Menores

No solicitamos datos de menores de 13 años. Si creés que un menor envió datos, contáctanos para eliminarlos.

Seguridad

Usamos salvaguardas físicas, electrónicas y procedimentales; las contraseñas se almacenan hasheadas.

Cambios

Esta política puede actualizarse. Las versiones vigentes se publican en esta página; el uso continuado implica aceptación.

Contacto

Para consultas sobre privacidad, escribinos a chanchoc.dev@gmail.com.
